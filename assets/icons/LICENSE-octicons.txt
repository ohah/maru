The following icons in this directory are derived from GitHub Octicons
(https://github.com/primer/octicons):

  bell.svg, chevron-down.svg, chevron-right.svg, folder.svg, gear.svg,
  git-branch.svg, mark-github.svg, plus.svg, reset.svg, search.svg,
  sidebar-collapse.svg

and their tight variants (same drawing, tighter view box or heavier stroke so
it fills a small slot; chosen in code as icons.Fit.tight, not as separate names):

  chevron-down-tight.svg, chevron-right-tight.svg, reset-tight.svg,
  search-tight.svg

(reset.svg is derived from the Octicons "sync" icon.)
