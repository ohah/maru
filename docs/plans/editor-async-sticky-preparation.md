# 비동기 완료의 심볼 요약 준비

상태: 실제 설치 재현·구현·Debug/ReleaseFast 집중 검증 및 같은 바이너리의 GUI 대조 48회/1,440입력 완료. PR·CI는 별도 상태다.

## 재현과 변경

PR #4668의 준비 뒤 주소 조사에서 비동기 main Running 표본은 고정 머리줄의
`Summary.hasSymbols → fullCount` 경로에 약 41%의 포함 weight를 보였다.
실제 Runtime 완료를 두 뷰에 설치하고 첫 `stickySymbols` 조회의 재구축 노드를 확인한 판정자는
수정 전 `expected 0, found 33`으로 실패했다. 시간 한도나 XML 이름만으로 재구축을 추정하지 않는다.

워커가 완료를 공개하기 전에 `Provider.prepareStickySummary`로 기존 심볼 분류·증분 집계를 준비한다.
`Provider.copyReady`는 이미 현재 요약을 독립 native 참조로 복사하므로 새 공유 저장소나 뷰 포인터는
추가하지 않는다. 원본 완료·수신 Provider·수신 요약의 참조는 서로 독립이며 최종 native 해제는
기존 완료 반환 경로를 따른다. 파싱·입력·Undo·선택·IME·렌더 정책은 바꾸지 않는다.

요약의 cold/증분 순회는 취소 플래그를 반복 확인한다. 중단된 부분 집계는 현재 판으로 발행하지 않는다.
선택적 캐시 준비의 OOM은 준비된 파싱을 버리거나 재파싱하지 않는다. 기존 `copyReady` 계약처럼
요약이 없는 뷰가 첫 조회에서 집계할 수 있다. 취소는 기존 worker 결과 거절·회수 경로로 간다.

## 범위

이번 변경은 심볼 요약에 한정한다. 접힘 캐시는 현재 별도 뷰 저장소이며 완료 설치의 기존 폐기를
유지한다. 접힘·괄호·색·심볼 목록·머리줄의 문서 판 검증을 느슨하게 만들지 않는다.
위치가 낡은 캐시를 다음 트리에 붙여 성능을 얻는 방식은 사용하지 않는다.

## 검증

- `test-editor-sticky-preparation`: 복제 뒤 원본 종료, 심볼 0개, 시작 전/전체 순회 중/증분 순회 중
  취소, 선택적 준비 OOM과 정상 후속 준비를 검사한다.
- `test-editor-parse-worker`: 기존 큐·스냅샷·본문 OOM·기준 격리·퇴역·종료에 더해 요약 준비 장벽에서의
  실제 취소 및 worker allocator OOM 뒤 파싱 보존을 검사한다. 현재 21개다.
- `test-editor-parse-view`: 실제 완료의 두 뷰 첫 조회 재구축 0, cold 트리·색 조회·보유/반환·옛 완료 거절을 검사한다.
- 기존 sticky snapshot/changes, 전체 syntax, 제품 sticky snapshot 및 일반 입력 회귀도 유지한다.

## 성능 대조

최신 메인에는 보관 앱 이후의 별도 자동완성 변경도 있어 다른 실행 파일의 시간을 직접 비교하지 않는다.
`prepare.py --stream --summary-control`은 외부 사본에만 워커 준비를 끄는 스위치와 실제 시도·준비·우회
계수, 마지막 뷰의 재구축 노드 조회를 넣는다. 제품 환경변수·설정·ABI에는 추가하지 않는다.

`summary_study.py`는 동일 실행 파일·동일 async 경로에서 준비 끔/켬을 인접 실행하며 반복 순서를
교대한다. 프로파일러는 붙이지 않는다. 각 조건의 실제 worker 분기·현재 뷰의 재구축, 입력 ID·문서·
프레임·표시·최종 색·설정 보존을 검증한다. 불완전한 행렬이나 실제 분기가 다른 실행을 채택하지 않는다.
준비가 있는 상태에서는 워커의 완료 지연도 생길 수 있으므로 첫 표시뿐 아니라 마지막 색 준비와
프로세스별 메모리도 보존한다. GUI 대조 전에는 개선율을 확정하지 않는다.


## 실행 결과와 다음 범위

[실측과 실패 경로](../../tools/editor-input-stream/summary-results.md)는 같은 실행 파일의
준비 끔/켬을 8조건에서 각각 3회 대조한다. 모든 조건의 첫 표시 중앙값·p95가 낮았고
켜진 24프로세스의 최종 뷰 재구축은 0이다. 작은 공유 문서의 한 조건에서는 최종 색 완료
최대가 늘어 그 표본도 보존했다. 이 결과를 모든 입력·언어의 개선으로 일반화하지 않는다.
다음 조사 후보는 별도로 남아 있는 접힘 승격의 재구축이다. 소유권을 먼저 재현·검증하고
별도 범위로 진행하며 이번 PR에 함께 이관하지 않는다.
