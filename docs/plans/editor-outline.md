# 활성 편집기 도크 아웃라인

상태: 구현. 사용자가 승인한 활성 문서 도크 아웃라인 작업이다. 심볼 피커의 임시 미리보기와 별개로, 기존 도크 안에서 활성 파일의 구조를 계속 볼 수 있게 한다.

## 동작

- 기존 도크에 Outline 뷰와 `Editor: Show Outline` 명령을 추가한다. 도크 위치·크기·선택 뷰 복원은 기존 계약을 따른다.
- 현재 리비전에 맞는 LSP `documentSymbol`이 있으면 사용하고, 없으면 현재 tree-sitter 결과를 사용한다. 문서 순서의 계층을 표시하며, 파싱 대기·심볼 없음·편집기 아님을 구분한다.
- 이름을 누르면 기존 `navigateTo`로 이동한다. 펼침 표시는 자식 표시만 바꾼다. 현재 커서가 속한 가장 안쪽 심볼을 강조하되 편집기 커서나 스크롤을 자동으로 바꾸지 않는다.
- 활성 파일·분할 포커스·문서 리비전·심볼 제공 결과가 바뀌면 목록을 갱신한다. 문서 리비전·뷰·심볼 제공 결과가 바뀌면 접힘 상태는 새 목록에서 다시 시작하며, 도크를 닫았을 때는 목록 계산을 하지 않는다.
- 이름과 범위는 목록이 소유한다. 누름과 놓음 사이 문서·리비전·목록·기하가 바뀌면 이전 행의 이동을 취소한다. 같은 행 동작 위에서 놓았을 때만 실행하며, 모달이나 창 포커스 전환에 끊긴 누름도 취소한다.
- 목록 생성이나 입력 표·접근성 스냅숏 발행에 실패하면 옛 위치를 실행하지 않는다. 접근성 임시 저장소는 해제하고 입력 표도 거두며, 발행은 다음 시도에서 복구한다. 목록 생성 실패 안내는 도크를 다시 열어 재시도한다.

## 구조와 검증

중립 편집기 모델은 심볼 정렬·계층·접힘·커서 포함 판정을 소유한다. Chrome 컴포넌트는 보이는 행만 immutable typed tree로 만들고 공통 interaction·semantic paint·접근성 서술자를 사용한다. 기존 macOS 접근성 조회 ABI로 라벨·계층·선택·펼침을 전달하며, VoiceOver 조작 완료를 뜻하지 않는다. AppSession 어댑터는 현재 문서 신원과 리비전을 재검증하고 기존 이동·도크 스크롤·Metal 텍스트 경로에 연결한다.

검증은 중립 모델의 잘못된 범위·중복 이름·접힘·할당 실패, 컴포넌트의 좁은 폭·배율·clip·세대, AppSession의 편집·분할 전환·누름 중 갱신을 포함한다. 깊이 축소 회귀는 `outline 깊은 계층도 접힘에서 자식을 남기지 않는다`의 합성 범위로, 반복 접힘은 별도 부모 모델로 대조한다. 실제 LSP 응답 해석기의 순번·편집 버전·빈 응답을 검사하고, 입력 표·접근성 발행에는 할당 실패를 주입한다. 공통 접근성 소비자의 직전 스냅숏 보존도 검사한다. 제품 앱에서 실제 도크 클릭·드래그 취소·스크롤·편집 후 갱신을 실행하고 Metal PNG를 PR에 첨부한다. 컴파일 가능한 동작 돌연변이와 같은 의미의 대조군으로 판정자의 효과를 확인한다.

프로젝트 전체 검색, 다른 파일 미리보기, 이름 정렬·필터 설정, 아웃라인 접힘의 재시작 보존은 이번 범위에 포함하지 않는다.

## 실행 경로

- `mise exec -- zig build test-editor-outline`: 중립 모델·컴포넌트 9개(등록 진입점 포함), 제품 문서 수명 20개(등록 진입점 4개 포함)를 개수 가드로 실행한다.
- `python3 tools/editor-outline-app/run.py --output /tmp/maru-outline-app-<새이름>`: 격리 HOME의 실제 앱에서 명령 열기, AppKit 클릭·행 밖 드래그 취소, 접힘, 편집, 공유 분할과 원래 뷰 전환, 하단 도크 끝 스크롤, 빈 문서를 관측한다. 원본 파일을 저장하지 않았는지도 확인한다.
- 캡처는 제품 Metal readback이며 PNG·관측 로그·소스와 바이너리 SHA-256을 남긴다. 물리 한국어 입력기와 VoiceOver 검증은 이 경로가 증명하지 않는다.
