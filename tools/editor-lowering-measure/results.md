# pane 내부 색 계산과 그리기 목록 변환 실측

선행 PR #4578의 제품 head `87df76047bda893cd1c89fc2ef60ff06225694ec`를 외부 사본으로 빌드했다. 제품 소스는 변경하지 않는다. 원본/계측 파일 18개와 실행 파일·표본 해시, 실제 실행 stdout/순서는 저장소 밖 `pane-lowering-attribution-detail/`에 보존한다. 전체 파일 수와 구간 집합은 setup metadata와 `run.py`의 계약이 소유한다.

기존 FRAME/PROVIDER/PANE schema 3 대조에 LOWERING schema 2의 9구간을 추가했다. 5파일 × 일반/공유 × 3반복의 성능 실행 30회·600입력과 별도 정확성 10회·200입력을 완료했다. 정확성 패스의 전체 sticky 대조는 300뷰이며 시간 측정 종료 뒤 수행한다. 모든 입력의 호출 수·시간 포함 관계와 상위 제품·fold/괄호·줄 대조도 유지한다.

## 독립 검증과 증거

다섯 독립 실패 가설에서 45개 손상을 거절했고 각 묶음 앞뒤 원본 및 최종 실제 자료 대조가 유지됐다. 표본/실제 순서, 각 구간 호출 수와 음수·부모 초과·합계 중첩, 상위 제품/정확성 불일치, 원본/계측/형식/실행 파일 변경, CLI의 다른 모델·기존 자료 재준비를 검사했다. `pane-lowering-detail-review.json`이 도구 세 파일의 해시를 묶는다.

현재 준비 도구를 새 임시 디렉터리에서 다시 실행해 원본/계측 18개 해시가 이미 빌드·실행한 사본과 같음을 확인했다(`pane-lowering-detail-preparation-replay.json`). 임시 사본을 빌드해 과거 수치를 대체하지 않았다. 기존 자료와 실행 파일은 그대로 보존한다.

초기 LOWERING schema 1(7구간)은 `pane-lowering-attribution-probe/`에 분리 보존했다. 확장한 현재 도구로도 43개 손상을 거절하고 원본 대조를 유지했다(`pane-lowering-schema1-review.json`). 초기/확장 실행의 분포를 합치거나 이를 전후 개선량으로 해석하지 않는다.

## 재현

```sh
python3 tools/editor-lowering-measure/run.py --output /외부/새-경로 --fixtures /외부/기존-고정-표본 --deps "$PWD/zig-pkg" --modes 1 --workloads typing,shared --repetitions 3
python3 tools/editor-lowering-measure/run.py --output /외부/새-경로 --deps "$PWD/zig-pkg" --resume --run-only --workloads typing,shared --prefix verify --verify-each-edit 1 --repetitions 1
python3 tools/editor-lowering-measure/summarize.py /외부/새-경로
python3 tools/editor-lowering-measure/verify.py /외부/새-경로 --receipt /외부/손상-검증.json
```

기존 표본 폴더는 앞선 측정의 fixtures를 사용한다. 원문·줄 수·해시는 inputs.json으로 확인한다. flat-N은 함수 N개이며 함수당 4줄이다. 새 실행은 별도 출력 경로에서 수행하고 기존 원시 로그·실행 파일을 덮어쓰지 않는다. 그림·픽셀·실제 OS 입력의 검증은 이번 계측 범위 밖이다.
