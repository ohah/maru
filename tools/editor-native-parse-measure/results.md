# Native 파싱·변경 범위 비용 실측

기준 제품은 실제 main `fc2d697cfbc4732f5dc06508b86832e50c19215a`다. 제품 코드는 바꾸지 않았다.
후속 main `1e1663c0d`의 LSP 변경과 합류했지만 이 표본은 그 변경 전 기준이다.
표의 시간은 추가 콜백 계수가 없는 기준 바이너리의 성능 30프로세스·600입력이다.
같은 기준 바이너리의 별도 정확성 10프로세스·200입력과, 추가 계수를 넣은 별도 진단
바이너리의 10프로세스·200입력을 구분했다. 준비 빌드 실행은 모집단에 넣지 않는다.
원문 다섯 개는 이전 자료와 바이트·해시가 같지만 옛 시간 표본은 섞지 않았다.
초기 외부 driver의 기준 자료는 별도로 보존했고, 이 표는 저장소의 재현 CLI로 수집한 자료를 사용한다.

입력 동작은 문서 중간 부근에 공백 한 글자를 20회 삽입하는 것이다.
구조 편집·대량 붙여넣기·Undo를 대표하는 표본은 아니다.

## 기준 시간

Provider 안에 native 파싱·변경 통지가 있고, 변경 통지 안에 변경 범위 계산이 있다.
서로 포함되는 시간이나 서로 다른 중앙값을 더하거나 빼지 않는다.
시계는 awake 경과시간이며 스레드 CPU 시간은 측정하지 않았다.

## 별도 진단의 호출 수

각 행은 정확성 대조를 켠 20입력이다. 진단의 실행 시간은 위 성능 표에 넣지 않았다.
모든 200입력에서 native 파싱은 한 번, 옛 트리 전달은 한 번, 완료는 한 번이었고
미완료·취소 반환은 0이었다. 이 실측 경로가 전달한 예산은 0이었다.
예산 0에서 중단하지 않는 기존 코드의 관측이며 실제 UI의 마감 준수나 모든 입력 경로의 예산을 검증한 결과는 아니다.

reader는 입력마다 한 번 호출됐다. reader가 제시한 길이는 원문 suffix의 길이이며,
파서가 실제로 소비한 바이트 수가 아니다. progress 호출 수도 방문 노드 수나 lexer 작업량으로 해석하지 않는다.
공유 뷰에서는 최초 입력에 범위 계산 두 번, 이후 입력에 한 번이었고 기존 범위 인계와 대응했다.
C API의 반환 범위 개수는 0이었지만 본문은 입력마다 바뀌었다. 빈 반환 범위만으로 다음 호출을 생략해도 안전하다고 판단하지 않는다.

## 판단과 남은 경계

큰 합성 Zig에서는 현재 제품에서도 native 파싱·범위 계산 비용이 관측됐다.
옛 트리가 없어서 매번 처음부터 파싱한다는 가설은 이 자료의 옛 트리 전달 기록과 맞지 않는다.
옛 트리 전달만으로 실제 노드 재사용을 증명할 수도 없다. 원인을 더 좁히려면 별도 native 작업량 진단이나
프로파일이 필요하다. 이 자료만으로 파싱 예산·Worker·저장소·UX를 변경하지 않는다.

## 고친 판정과 검증

JSON의 `true`나 `3.0` 같은 값이 정수 스키마 버전을 대신하지 못하도록 타입을 검사한다.
기준·진단 바이너리의 해시가 같아도 통과하던 빈틈도 막았다. 이전 판독기 소스를 이전 기록의 해시로 복원해
일관되게 바꾼 공유 바이너리를 수락하는 것을 재현했고, 최종 판독기의 거절과 정상 자료 보존을 확인했다.

다섯 독립 가설은 모집단/제품 대조·스키마/역할·native/reader 대응·시간/범위 대응·근거/CLI 신원이다.
실제 기록 손상 29건을 거절하고 가설 전후 정상 대조 10건과 마지막 원본 대조를 통과했다.
원시 로그 해시도 맞춘 의미 손상은 해당 의미 판정까지 도달시켰다. 컴파일 오류나 선택 개수 오류는 검출로 세지 않았다.
단위 검사 8개와 독립 token reader의 시간 180필드·콜백 140필드·첫 입력 10그룹 대조도 통과했다.
추가 실제 C 양성 대조에서 초기 파싱의 옛 트리 전달 0회·reader 2회·EOF 1회,
구조 변경의 반환 범위 1개, 강제 만료 조건의 취소 반환 1회·미완료 반환과 이후 재개 완료를 확인했다.
만료 조건은 이 대조 사본에만 강제했다. 성능 바이너리·200입력 진단·실제 UI 기한 검증과 구분한다.
전용 C 대조 한 개와 import 검사 한 개가 모두 통과했다. 최초 선택 가드 5개는 실제 선택 2개와
달라 거절됐으며, 그 로그를 보존하고 올바른 가드의 새 사본만 채택했다.
