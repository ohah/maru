# Provider 편집 비용 귀속 결과

이 표는 입력 판으로 완료 트리를 재사용하기 전 `per-view-native` 실행의 schema 1 기록이다.
새 실행 모델의 호출 수와 전후 실측은 [별도 재사용 계획](../../docs/plans/editor-shared-parse-reuse.md)을 따른다.

성능 30회/600개 입력과 별도 매 입력 전수 대조 10회/200개 입력을 완료했다.
각 파일·입력의 성능 집계는 3회 실행의 60개 입력이다. 단위는 ms다.
일반 입력은 매 입력 Provider·native 파싱·변경 범위 계산 각 1회, 공유 입력은 각 2회를 확인했다.

`Provider`는 C 파싱·변경 통지·트리 편집을 포함하고, 변경 통지는 C 범위 계산을 포함한다.
중첩 구간을 합하지 않는다. 서로 다른 구간의 중앙값도 부모 중앙값과 같게 더해지지 않는다.
각 입력에서는 겹치지 않는 하위 구간의 합이 부모 안에 있는지 별도로 검증했다.
